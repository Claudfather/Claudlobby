# Eval Workflow

An eval exists to change a decision: if no result would change what you ship, do not run one. When one is due, invoke the `run-eval` skill **before the first run**. It starts by writing down what would convince you, which is worth nothing once you have seen results, and it holds every other rule of the eval. **INCONCLUSIVE is a real result and is never rounded up to PASS.**
