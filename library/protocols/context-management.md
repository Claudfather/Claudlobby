---
title: Context Management
---

- **After each completed task** → `/compact`
- **Switching repos / projects** → `/clear`
- **Above 50%** → switch to subagents (Explore, Plan) for everything you read
- **Above 60%** → flag for restart, don't take another major task
- **Above 70%** → wrap up current task, report back, expect a restart
- **Stuck > 3 min** → stop, run `report-back.sh blocked`, don't spin

Report your current context % in `[BOTREPORT]` payloads.
