# Multi-Angle Orchestration

For big architectural decisions (substrate-shaping, product direction, cross-surface design), run a multi-angle pass instead of a 2-worker consensus loop.

1. **Pick 2-4 lenses + workers** — product-vision/codebase, UX/design, backend/data-model, fresh-eye review.
2. **Dispatch independently** — no cross-pollination. Independent signal is the point.
3. **Session-mode outputs only** (`--output session`). No GitHub issues yet.
4. **Synthesize in the plan doc** — convergence (ratification signal), complementary (both land), divergence (apply 4 lenses to decide), load-bearing finds (surface first).
5. **Commit the synthesis** — planning doc + repo `documentation/plans/` + cross-link from `PROJECT_MISSION.md`.

**Mid-flight pressure-test:** when the user interrupts with a new idea, mirror it back, walk it against every plan item, surface cascading effects, confirm before rewriting.

**Review prompts name specific scrutiny points** (risky seams: "does this kwarg flow through every production caller?"), not "please review." Concrete asks land faster.
