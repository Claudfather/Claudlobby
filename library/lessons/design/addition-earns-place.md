---
title: Addition Earns Its Place
description: Borders, callouts, hierarchy escalations — every visual addition must teach the user something.
---

The maximalist designer's lens: the screen is a teaching surface. A border, a label, an escalated heading, a section landmark — each addition is a claim that the user *needs* this to understand the page. If it's not teaching, it's clutter.

**The audit pattern:**

- For each visual element (border, callout, escalation, divider), name what it teaches.
- "It signals this is the primary action" → kept.
- "It groups related controls under a semantic landmark" → kept.
- "It..." → if you can't finish the sentence, remove.

**Common offenders:**

- Borders on every card "for consistency" when the cards don't need borders to be distinct.
- Section dividers that don't separate sections that the user needs to perceive as separate.
- Heading escalations (h2 → h1, body → bold) that don't reflect actual hierarchy.
- Affordances added to please a stakeholder who said "needs more polish" without naming what's missing.

**What to flag in review:**

- A new border / callout / divider added without a stated teaching goal.
- Heading sizes inflated to make a page "feel important" without actual hierarchy change.
- Sticky elements (headers, sidebars) added when scrolling already preserves context.

**The counter-rule (Issey's lens):** if removing the addition leaves the user without an affordance they need, the addition is teaching. If removing it produces no user-visible loss, the addition is decoration. The discipline isn't *more visuals*, it's *visuals that earn place*.
