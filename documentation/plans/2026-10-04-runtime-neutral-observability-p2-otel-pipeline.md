## Summary

Two PR legs with a one-week canary between them. **PR P2-a** buys the intra-session layer per F3(b)/F4(c)/F5:
a `telemetry` mapping in `fleet.yaml` composed into an armed Claude bot's `bot.conf`; two dormant `unit: service`
host jobs (`otel-collector`, running operator-installed `otelcol-contrib` on a composer-rendered config, and
`plane-otel`, a stdlib OTLP/JSON intake that translates a seven-item allowlist into `emit_batch` batches posted
to the daemon's socket); the `config plan` refusal for an enabled bot on a host with no enrolled Collector; the
derive-not-mint rule for `session` subjects; registry, switch and doc rows; then the one-bot, one-host, one-week
canary on an independent canary root. **PR P2-b**, only after that canary passes its stated budget and C6 holds,
stops `bot-vitals.sh` emitting `tool_call` (~84 % of system-event volume, `claudlobby/plane/retention.py:84-87`),
removes its dead `session_event` path, fixes #874's cwd fallback in the same file, and decides design v2 §9b's
usage items on the canary's evidence. Deliberately left to others: Codex composition (`[otel]`, F11, the companion),
traces (none composed, §2.3), and any reader UI over `session.*` samples.

```python
@dataclass(frozen=True)
class TelemetryConfig:
    enabled: bool = False          # STRICT bool (#2145 F4): the arming knob
    content: str = "metadata"      # metadata | full — KNOWN_TELEMETRY_CONTENT

_TELEMETRY_KEYS = ("enabled", "content")

def _parse_telemetry(raw: Any, where: str) -> dict:
    """One tier's `telemetry:` → the fields it SETS (absent keys stay absent so the merge inherits them)."""
    if raw is None:
        return {}
    raw = _shaped(f"'{where}'", raw, dict, "{enabled: true}")
    unknown = sorted(str(k) for k in raw if k not in _TELEMETRY_KEYS)
    if unknown:
        raise ValueError(f"'{where}': unknown key(s) {', '.join(unknown)} — accepted: {', '.join(_TELEMETRY_KEYS)}")
    out: dict = {}
    if "enabled" in raw:
        out["enabled"] = _strict_bool(f"'{where}.enabled'", raw["enabled"])
    if raw.get("content") is not None:
        out["content"] = _parse_enum(f"{where}.content", raw["content"], KNOWN_TELEMETRY_CONTENT)
    return out

def _merge_telemetry(defaults_raw: Any, bot_raw: Any, name: str) -> TelemetryConfig:
    """Field-wise: bot over defaults over built-in (observability's precedence, isolation's strictness)."""
    return TelemetryConfig(**{**_parse_telemetry(defaults_raw, "defaults.telemetry"),
                              **_parse_telemetry(bot_raw, f"bots.{name}.telemetry")})
```

## Stated limitations

- **The `file` exporter is alpha.** Its rotation keys are the only retention knob (`--retention-days` → `max_days`); a future rename breaks the rendered config at `otelcol-contrib validate`, which the test leg catches where the binary is present and the golden comparison does not. `otlphttp` and the `otlp` receiver are stable.
- **Codex composition is the companion's (F11).** This PR ships the Codex transform statements and a fixture-tested intake leg only; a Codex session carries no bot (`fleet = "_host"`, no `subject_parent`) until the companion stamps `[otel] environment = "bot:<fleet>/<bot>"` (C5), and `metrics_exporter = "none"` + `[analytics] enabled = false` are the companion's lines (§11).
- **No traces.** Nothing is composed to export them (beta on Claude Code, undocumented on Codex; §2.3); the envelope's `trace_id`/`span_id` stay unwritten.
- **The intake keeps no cross-window state.** A restart loses at most the open windows; a session's total is `SUM(value)` with that bound stated in every `METRIC_NAMES` description.
- **The semconv pin is a commit, not a release** (the GenAI conventions repository has no tag). F5's attribute names stand; a rename is absorbed in one file, and `METRIC_NAMES`/`SYSTEM_EVENT_SEVERITY` are the reader surface that does not move.
- **`subject_parent` is an additive wire field.** An older daemon refuses a session sample with it; the intake drops and counts the batch, and the raw file still holds the data. Activation restarts the daemon with the intake, so the window is the activation itself.
- **`config explain` learns one dotted level** (`telemetry.enabled`, `telemetry.content`); the whole mapping stays "unsupported", as a mapping has no single origin.
