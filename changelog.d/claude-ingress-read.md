### Added — update-status can say whether this computer's private route is already exact (#3125)

`host-install-v1.sh update-status` takes an optional `ingress_node_key`. With it the answer adds `ingress`: `exact` when the system Tailscale daemon (root-run, `Running`, `TUN`, the version the root card admits, the named node, its `ts.net` name in `CertDomains`) already serves exactly the route the root ingress card would set for this account, by that card's own predicate copied byte for byte and held to `linux-system-v1.sh` by a parity test; `differs` when a fact read is otherwise or the card would refuse what Serve holds; `unknown` when anything could not be read, and always on a Mac. `exact` means only that the card could not change Serve, not that it would succeed or that a root ingress receipt exists: the card also checks what this read cannot. The read writes nothing and never makes the action refuse. Without the key the answer is byte for byte today's, and nothing a person sees changes until the website reads it after a later pin.
