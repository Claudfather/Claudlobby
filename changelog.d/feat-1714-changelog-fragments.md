### Changed — each PR adds its changelog entry as its own file in `changelog.d/`, and a weekly roll-up moves the files into this one (#1714)

Every PR used to add its entry at the top of this file, so each merge left every other open PR that carried one in conflict: on 2026-10-07, 13 of the 17 open PRs with an entry inserted it at the same line. Now a PR adds `changelog.d/<head branch, each / as ->.md` instead, and once a week `python3 bin/changelog.py assemble` moves the fragments in here, newest merge first. A new required check, `Changelog fragment`, refuses a PR that adds no entry unless its description says `Changelog: none — <why>`; it also refuses a fragment named for another branch and an entry written straight into this file outside a roll-up. `changelog.d/README.md` has the format.
