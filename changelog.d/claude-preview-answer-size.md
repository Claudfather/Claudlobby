### Fixed — a browser can show a first team's Preview

On a real computer the first browser Preview prepared its team and then could not be shown: the page said it could not get an answer, and Launch never became available. The Preview's answer, and the setup read that repeats it, carried each unit's environment and admission data. For a real first team that made the answer about 154 KB, more than the 131,072 bytes a browser accepts as one setup answer, so every read of it was dropped. `claudlobby/plane/owner_setup.py` now answers each unit without that working data (`shown_effects`); the same team's answer is about 57 KB. Nothing a person reads is lost: the page shows how many files change and which bots start. Launch is unchanged: the computer launches its own rendered plan, by fingerprint, and never read this answer.
