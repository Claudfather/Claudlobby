### Changed — the installer's size as sent is bounded here, as the website bounds it

The website's carrier sends `host-install-v1.sh` as one exec argument, `[/bin/]sh -c '<installer, each single quote escaped>' host-install <verb>`, and Linux refuses one argument over 131072 bytes. The website's own test keeps that command 4096 bytes under the limit; nothing in this repository bounded the installer, so a change that grew it past the website's bound passed here and failed only in the website's pin pull request. `tests/test_host_install.py` now checks the same command for all five verbs, with and without `/bin/`, against the same bound. Today the longest command is 117,703 bytes, 9,273 under it. `_original_launch` in `commands/host_owner_setup.py` had no caller and is removed. No script bytes change.
