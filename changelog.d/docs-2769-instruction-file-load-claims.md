### Docs — the instruction-files page says which sessions load the root `CLAUDE.md`, and the root file's pointers say what they lead to (#2769)

`documentation/instruction-files.md` says that a composed bot does not load the data root's `CLAUDE.md` (the composer lists it under `claudeMdExcludes` in each bot's settings) and that a bot that opens a file in one of its own checkouts loads that folder's `CLAUDE.md`. In the root `CLAUDE.md`, the pointers to `documentation/architecture/overview.md` name what they lead to: the definitions of `library/skills/` and `library/`, how the compositor reads `fleet.yaml`, the task, assignment, message and report commands, and the other key concepts, which have a line of their own under the key concepts; the `library/` line points at that page. `library/lessons/review/empirical-verification.md` points at `documentation/validating-bot-changes.md` for the Deliver → Add config → Recompose → Observe loop. `AGENTS.md` stays a byte copy of the root `CLAUDE.md`.
