### Fixed — `code-audit-sweep` and `sweep` call clauDNA's audit by its lenses, and run `data-model` only by hand (#2985)

`code-audit-sweep` takes the audit types `tech-debt`, `security`, `docs` and `product-enhance`, and runs `/claudna:audit <audit-type> --auto --output github`, or `/claudna:product-enhance --auto --output github` for `product-enhance`, which takes no lens; a type outside that list runs no audit and emits `audit_failed` with a reason that names it, so the `fleet.sweep.audit_types` examples in `documentation/fleet-yaml-schema.md` and `documentation/advanced-patterns.md` now read `[tech-debt, security]`. The `sweep` rotation runs `tech-debt`, `security` and `docs`, and its `--type` hint names the same three. Both skills say that the audit's `data-model` lens runs by hand in an attended session, because an `--auto` run of it reports `blocked`.
