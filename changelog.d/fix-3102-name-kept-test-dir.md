### Fixed — a failed test run names the directory it keeps, whichever test ran last (#3102)

A pytest session with a failed test keeps its `ct-*` directory (the session's home, config, cache, state, data and temp directories) so that someone can read it. The session fixture in `tests/conftest.py` printed `retained failed-test files: <path>` in its teardown, which pytest runs inside the last test's teardown with output captured, so the line showed only when that last test failed, or under `-s` or `-rP`. The fixture now records the kept directory, and the conftest's `pytest_terminal_summary` names it in pytest's closing summary, once, whichever test ran last. A passing session still removes its directory and names nothing. This change names kept directories; it does not remove them or bound how many there are.
