### Fixed — a sign-in the person cancelled is a plain note, and Message team no longer hides the computer card's buttons

In the workspace view's Claude sign-in step, the line after the person presses Cancel sign-in ("The sign-in stopped before a code was sent. Choose Try again for a new sign-in link.") was drawn in the same attention style as a fault or a timeout. Nothing is wrong when the person chose it, so that line is now an ordinary note, still announced as a status, with Try again the one filled action. Timeouts, failures and the approval-expired ending keep the attention style. With one team on one computer on a wide screen, opening Message team after Computers & status narrowed the teams line and could leave the computer card's Check connection button below its fold; the line now shows the card again when Message team opens. A wheel scroll or a press on the teams line itself (its scrollbar) now counts as using the Computers & status drawer, so a drawer opened for attention no longer closes under someone scrolling it. No words change.
