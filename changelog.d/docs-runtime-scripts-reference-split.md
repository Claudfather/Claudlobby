### Docs — a session that opens a runtime script no longer attaches the whole script reference

`claudlobby/_runtime_scripts/CLAUDE.md` keeps its placement guidance and authoring rules, and its "Script reference" table moves word for word to `documentation/runtime-script-reference.md`: the same 88 rows, in the same order. Claude Code attaches that folder's `CLAUDE.md` whole the first time a session opens a file there, which is now 3,128 bytes instead of 134,323. A row is one line that opens with its script's name, so a grep prints it; the folder file says to read a script's row before changing the script, and the root `CLAUDE.md` names the new file. Neither Claude Code nor Codex loads it on its own, and a wheel install does not ship it; a runtime that runs from a git working tree has it in that tree. Each `AGENTS.md` stays a byte copy of the `CLAUDE.md` beside it. Whether sessions still read a row before changing a script is not measured.
