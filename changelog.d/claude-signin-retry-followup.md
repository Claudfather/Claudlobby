### Fixed — Claude sign-in offers Try again as soon as no code can be taken, and a lost Try again answer no longer strands setup (#3022)

An attempt that has taken no code by its code cutoff (20 seconds before its five minutes, or before the setup approval ends) now ends there as a timeout, so Try again appears right away. Before, the panel kept showing a link that could no longer accept a code until the full five minutes had passed. A Try again now keeps the ID it replaces beside the new one in browser storage. If the answer to that Try again is lost and the computer still names the replaced attempt, which proves the new one was never started, the page follows the replaced attempt again, also after a reload. A refused or never-sent Try again is also undone when the connection changed meanwhile, for example after a failed session renewal. A sign-in is no longer started when the setup approval has less than 50 seconds left, which would only have spent one of its three attempts.
