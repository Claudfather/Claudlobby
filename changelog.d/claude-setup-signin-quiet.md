### Changed — the setup panel's sign-in step drops its manual check while the page checks by itself, and done steps show one tick

While the first-team setup panel checks Claude sign-in automatically (from "Starting Claude sign-in…" until the attempt connects or ends), it no longer also offers **Check sign-in progress**, which only repeated that check and contradicted "This page checks for progress automatically." The step then shows Open Claude sign-in, Copy link, the code field with Submit code, and Cancel sign-in. Check sign-in progress returns, as before, once automatic checks stop: after a check that could not reach the computer (where it is the one filled action) and after an attempt ends. A done step's line no longer repeats the ✓ its step mark already draws: it reads "Connected", "Setup approved", "Claude connected", "Goal: …", "Team preview prepared" or "Team launched". What each action sends, and when, is unchanged.
