# Planning

Plans, designs, and research output. Each subdirectory maps to a plan type:

- `design/` — Feature and system design plans (implementation-ready specs)
- `sprint/` — Sprint plans and retrospectives
- `migration/` — Migration plans (data, infra, schema changes)
- `exploration/` — Research, spikes, and pre-scope output (not yet implementation-ready)

Plans use frontmatter: title, type, status (draft/active/completed), owner, created date.
Completed plans move to `documentation/archive/` or stay in place with status: completed.
